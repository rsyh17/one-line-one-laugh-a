A tiny Node program (stdlib only) that writes a single one-line joke to `entry.txt`. The line is a self-contained savings-plan gag — cash hidden in the bedroom, rebranded as a bank with extremely limited hours and one very nervous security guard: the saver himself. It is 132 characters, inside the 1–140 character gate.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes `out/entry.txt` with the entry text, byte-identical on every run. Without `MAKEFUN_OUTPUT_DIR`, it defaults to `/output/entry.txt`.
